# Node.js Fundamentals Challenge

A Rocketseat Ignite challenge that extends a framework-free Node.js API with CSV import and stream processing.

## Project goal

Consolidate Node.js fundamentals by implementing task management endpoints and importing large inputs through streams.

## Features

- Create, list, update and remove tasks
- Mark tasks as complete
- Search task records
- Import tasks from CSV

## Technologies

- **JavaScript**
- **Node.js**
- **Node.js Streams**
- **csv-parse**
- **csv-generate**

## What I learned

- Building CRUD behavior without a web framework
- Processing CSV data as a stream
- Handling route parameters and query filters
- Keeping persistence and HTTP concerns separated

## Running locally

```bash
npm install
npm run dev
```

## Project status

This is a learning project and is not presented as a production-ready application.
